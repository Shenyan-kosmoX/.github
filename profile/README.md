### 从我们自己的工作开始

我们是一支正在科研与创业中探索的年轻团队。做研究、开发工具、整理和表达自己的想法，是我们每天面对的具体事情。Shenyan-kosmoX 就从这些工作中开始，以 **AI for Science** 为主线，建设一个开放的科研共同体。

在我们的科研实践中，一项工作常常从论文中的方法开始：把它变成程序，运行起来，再找别的方法核对结果。AI 帮助推进了其中许多步骤，也让原先觉得很难着手的工作有了新的入口。与此同时，一个结果为什么可信，仍然需要我们亲自追问。

这些尝试让我们开始想：既然获得和使用知识的方式正在变化，为什么一个人能够研究什么，还要完全由他过去学过什么、身边有什么资源来决定？

**我们尊重前人走过的道路，却不相信后来的人只能沿着同一条道路前行。**

### 把做过的工作，整理成别人可以接着用的东西

从一篇论文到一个能运行的模型，中间有许多没有写在文章里的工作。参数怎样选、结果怎样核对、哪些尝试没有走通，都可能影响后来的人能否真正用上它。

我们希望把这些一起留下。围绕长期科学问题维护计算工具箱，让代码、案例和验证方法随着研究逐渐完善。你可以运行一个已有实验，换一种方法再试，也可以让自己的 Agent 使用同一套环境。

团队在阅读、写作和表达中做出的工具，也会在这里分享。每个项目介绍它能帮人做什么，以及作者为什么愿意把它继续做下去。

**首批项目整理中。** 公开后，你可以在这里找到代码、运行案例和接下来想一起解决的问题。

[了解研究与工具 →](https://github.com/Shenyan-kosmoX/community/blob/main/docs/RESEARCH.md) · [介绍你的项目 →](https://github.com/Shenyan-kosmoX/community/blob/main/docs/PROJECT-INTAKE.md)
