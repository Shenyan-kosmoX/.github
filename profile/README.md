Shenyan-kosmoX 是一个正在建立的 **AI 原生开放科研共同体**。我们通过开放工具、研究支持与共同协作，帮助研究者跨越专业和资源的边界，将个人探索积累为可以被继承、检验和扩展的科研能力。

### 一个起点，不是一条预定的道路

我们出生在一个已经被解释、分类和组织过的世界。专业、机构和资源影响着我们能够接近什么问题；有时，一个人还没有开始尝试，就已经相信某条道路不属于自己。

这些边界有其历史，也可以有新的可能。AI 与开放知识正在改变人获取和运用能力的方式。我们希望把这种变化落实为可以使用的工具、可以检查的证据，以及可以共同推进的研究。

**解放**　重新审视那些被视为个人边界的现实条件。<br />
**创造**　从自己的问题出发，形成理解，让想法接受检验。<br />
**继承**　把探索所得留下，使后来者拥有更好的起点。

[阅读完整 Manifesto →](https://github.com/Shenyan-kosmoX/.github/blob/main/MANIFESTO.md)

### 共同建设可以继续生长的科研能力

研究项目组织持续的协作。模型、算法、案例与验证方法构成可版本化的研究环境，让人和 Agent 都能运行、检查和扩展已有工作。

首批项目正在准备公开接入。本页将链接实际可运行的仓库、能力说明与验证记录；尚未接入的研究不计为已发布成果。

[研究项目如何接入 →](https://github.com/Shenyan-kosmoX/community/blob/main/docs/PROJECT-INTAKE.md)
