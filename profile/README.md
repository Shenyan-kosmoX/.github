**Shenyan-kosmoX 是一个以 AI for Science 为主线的开放科研共同体。**

我们借助 AI 开展研究，也共同建设科研工具：将论文中的方法写成程序，整理可以运行的实验，留下核对结果的依据。研究者可以使用这些工作，提出自己的问题，再把改进分享回来。

### 让研究多一些可能

专业、资源和过往经历影响着一个人从哪里开始，却不该替他决定还能走向哪里。当知识与工具有了新的使用方式，我们希望更多人能亲自尝试那些一直好奇、却迟迟没有着手的问题。

[阅读 Manifesto →](https://github.com/Shenyan-kosmoX/.github/blob/main/MANIFESTO.md) · [认识发起团队 →](https://github.com/Shenyan-kosmoX/community/blob/main/ABOUT.md)

### 研究与工具

我们围绕长期科学问题维护计算工具箱，整理模型、代码、运行案例与验证方法。研究和创作中用到的 skill、资料整理与表达工具，也会在这里分享。

**首批项目整理中。** 公开后，你可以在这里找到代码、运行案例和接下来想一起解决的问题。

[查看项目目录 →](https://github.com/Shenyan-kosmoX/community/blob/main/docs/RESEARCH.md)
