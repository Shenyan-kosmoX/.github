一篇读不明白的论文，一个总是对不上的结果，一个和自己专业无关、却一直放不下的问题——研究可以从这些地方开始。

**Shenyan-kosmoX 是一个 AI 原生开放科研社区。** 我们希望借助 AI、开放工具和研究支持，让更多人有办法亲自试一试：把问题变成模型，把方法写成代码，再看看结果究竟说明了什么。

### 有些路，可以由自己开始走

我们学过的专业、能够获得的资源，影响着研究从哪里开始。但一个人还想走多远、想弄清什么，值得留一点空间给他自己决定。

这里欢迎刚开始学习的人，也欢迎已经研究了很久、想换个方向试试的人。你可以带来想法，也可以带来做到一半的工作，或者一个让你卡住的问题。

[我们为什么建立这个社区 →](https://github.com/Shenyan-kosmoX/.github/blob/main/MANIFESTO.md)

### 做过的研究，能让下一个人接着做

搭好一个模型、找到一组能复现的参数、弄清一种方法为什么失效，都要花时间。把这些过程整理下来，后来的人就能从这里继续。

我们围绕长期研究问题建设开源工具箱，留下代码、案例、运行环境和验证方法。你可以运行一个已有实验，修改它，也可以让自己的 Agent 从同一套工具开始工作。

**首批项目整理中。** 公开后，你可以在这里找到代码、运行案例和接下来想一起解决的问题。

[把你的项目带进来 →](https://github.com/Shenyan-kosmoX/community/blob/main/docs/PROJECT-INTAKE.md)

### 找一件你想开始的事

| 如果你现在…… | 可以从这里开始 |
| --- | --- |
| 有个想法，想找人聊聊 | [发起讨论](https://github.com/Shenyan-kosmoX/community/blob/main/docs/DISCUSSIONS.md) |
| 跑出了不同的结果，或者想改进一处工具 | [参与贡献](https://github.com/Shenyan-kosmoX/community/blob/main/CONTRIBUTING.md) |
| 已经做了一些工作，想继续共同维护 | [介绍你的项目](https://github.com/Shenyan-kosmoX/community/blob/main/docs/PROJECT-INTAKE.md) |
| 想为一段研究申请 API 额度 | [了解研究支持](https://github.com/Shenyan-kosmoX/community/blob/main/docs/RESOURCES.md) |

不必等想法完全成熟再开口。把你看到的、试过的、还没想明白的说清楚，就已经是一次有用的交流。
